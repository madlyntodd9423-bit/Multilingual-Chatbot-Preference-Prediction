### 简短结论

从表中可以看出，**Exp2 是当前最好的模型方案**。它的 accuracy 达到 **0.6153**，macro F1 达到 **0.6113**，明显高于 baseline 和 exp1。Exp1 虽然比 baseline 有提升，但后期 valid_loss 和 log_loss 上升，说明存在过拟合。Exp3 虽然使用了 regression 形式，但预测几乎退化为单一类别，实际分类能力接近 baseline，不建议作为最终模型。



下面按 **baseline、exp1、exp2、exp3** 分别分析数据走势。整体结论先说：**exp2 最强，但第 4 epoch 后明显过拟合；exp1 有提升但更早过拟合；baseline 基本没学到；exp3 回归版本发生预测坍缩，几乎不可用。**

Baseline 的 `train_loss` 从 **0.6976 降到 0.6940**，下降幅度非常小；`valid_loss` 一直围绕 **0.693** 波动。对于二分类任务，log loss 接近 **0.693** 通常说明模型输出接近 0.5，也就是没有明显判断能力。

### 概率分布走势

第 8 epoch 的 valid_loss 已经达到 **1.8933**，log_loss 达到 **1.8949**，但 accuracy 仍有 **0.5633**，说明模型虽然还能分对一部分样本，但概率校准非常差。

**结论：Exp1 有效，但最佳停止点应在 epoch 3 或 epoch 4。若看 log_loss，选 epoch 3；若看 accuracy，选 epoch 4。继续训练会明显过拟合。**

Exp2 从 epoch 1 到 epoch 4 的 accuracy 从 **0.5357 → 0.6153**，macro F1 从 **0.4585 → 0.6113**，是所有模型中表现最好的走势。它在 epoch 4 保存 best checkpoint，best accuracy 为 **0.615320**。

### 为什么 Exp2 比 Exp1 好？

Exp2 加入了 **swap**，也就是交换 response A / response B 的增强方式。这会让模型更难记住位置偏差，而是被迫学习两个 response 的相对质量。因此它的 early-stage 提升明显比 Exp1 更快。

对比关键点：

| 指标          | Exp1 最好 | Exp2 最好  | 结论                          |
| ------------- | --------- | ---------- | ----------------------------- |
| Best Accuracy | 0.5781    | **0.6153** | Exp2 明显更强                 |
| Best Macro F1 | 0.5781    | **0.6113** | Exp2 类别平衡更好             |
| Best Log Loss | 0.6751    | **0.6599** | Exp2 概率质量更好             |
| 过拟合速度    | 中等      | 更快更严重 | Exp2 学得更强，也更容易过拟合 |

### 过拟合走势

Exp2 的过拟合非常明显。epoch 4 之后，`train_loss` 从 **0.6109** 降到 epoch 8 的 **0.1327**，说明训练集拟合越来越强；但 `valid_loss` 从 **0.7007** 升到 **2.5164**，log_loss 也升到 **2.5162**。 

这说明模型后期不是单纯“继续变好”，而是在训练集上越来越自信，在验证集上越来越不可靠。虽然 epoch 8 的 accuracy 还有 **0.5937**，比 baseline 高很多，但概率质量已经很差，不适合拿最后 epoch 作为最终模型。

### 概率分布走势

Exp2 的 `prob_model_b std` 从 **0.0619 → 0.4767**，越来越接近极端输出。epoch 8 时，概率最小值接近 **0.000033**，最大值接近 **0.999983**，说明模型大量输出接近 0 或 1 的极端概率。

**结论：Exp2 是目前最好的方案，但最佳保存点应选择 epoch 3 或 epoch 4。若比赛指标偏 log_loss，epoch 3 更稳；若更重视 accuracy，epoch 4 最好。绝对不建议使用 epoch 5–8 的最终权重。**

Exp3 的问题非常明显：score 几乎固定在 0.5 附近。例如 epoch 2 的 score mean 是 **0.503878**，std 只有 **0.000100**，并且预测标签是 **全 1，共 19034 个样本**；epoch 4 也是全 1。

### 为什么说它坍缩？

因为它的预测不是在学习样本差异，而是在 0.5 附近轻微上下波动：

- score 稍微低于 0.5，就全部预测 0；
- score 稍微高于 0.5，就全部预测 1；
- accuracy 因此只是在 **0.4919 和 0.5081** 之间来回跳。

epoch 1 是全 0，epoch 2 是全 1，epoch 3 又是全 0，epoch 4 又是全 1，这不是正常学习曲线，而是典型的 **输出坍缩到常数附近**。

到 epoch 8，虽然不是完全单类，但预测仍然是 **0: 18988, 1: 46**，几乎全部预测为 0；CV summary 中 accuracy 也只有 **0.508091**，log_loss 为 **0.693029**，仍然接近随机水平。

### MSE 看起来稳定，但没有实际意义

Exp3 的 valid_loss / MSE 一直在 **0.25** 附近，MAE 一直在 **0.5** 附近。这说明模型大概率一直输出接近 0.5。对于二分类标签 0/1，如果模型恒定输出 0.5，那么：

- MSE ≈ 0.25；
- MAE ≈ 0.5；
- log_loss ≈ 0.693；
- accuracy 取决于阈值后偏向哪一类。

所以 Exp3 的 MSE 稳定不是好事，而是说明它没有真正学到分类能力。

**结论：Exp3 不建议继续使用 regression 方案。除非重新设计目标函数、输出层、阈值策略或损失函数，否则它明显弱于 Exp1 和 Exp2。**
